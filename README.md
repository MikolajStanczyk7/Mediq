Mediq

Mediq to mobilna aplikacja dla lekarzy, która działa offline.  
Pozwala szybko zarządzać pacjentami i ich wynikami badań bez internetu.

Projekt stworzony na konkurs "Złota Apka Kalisz 2026"/"Golden App Kalisz 2026".

Funkcjonalności:
- dodawanie, edycja i usuwanie pacjentów,
- zapisywanie wyników badań,
- podgląd historii i podstawowych statystyk,
- możliwość dodawania zdjęcia do wyników,
- obliczanie BMI,
- lokalna baza danych SQLite (offline).

Technologie
React Native, Expo, TypeScript, SQLite.

Uruchomienie
```bash
npm install
npx expo start
