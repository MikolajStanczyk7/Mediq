Mediq

-English
Mediq is an offline mobile app for doctors.  
It helps manage patients and medical results quickly, even without internet access.

This project developed for the "Golden App Kalisz 2026" competition.

What it offers:
- adding, editing, and deleting patients,
- saving medical test results,
- viewing history and basic statistics,
- attaching photos to results,
- BMI calculation,
- local SQLite database (offline).

Tech stack
React Native, Expo, TypeScript, SQLite.

Run
```bash
npm install
npx expo start
```
Link to download the APK (just download it to your phone and run it):
